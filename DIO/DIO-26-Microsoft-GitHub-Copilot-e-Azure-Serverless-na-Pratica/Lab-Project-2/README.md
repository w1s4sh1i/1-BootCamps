## Descrição do Desafio

Com objetivo de praticar o processo de configuração de uma instância de Banco de Dados na plataforma Microsoft Azure. 

**Entregável do desafio proposto**: Criação de um repositório contendo resumos, anotações e dicas sobre o uso da Azure, ao servir como material de apoio para estudos e futuras implementações.

## Objetivos de Aprendizagem 
Ao concluir este desafio, você será capaz de: 

1. Aplicar os conceitos aprendidos em um ambiente prático;

2. Documentar processos técnicos de forma clara e estruturada; 

3. Utilizar o GitHub como ferramenta para compartilhamento de documentação técnica.
